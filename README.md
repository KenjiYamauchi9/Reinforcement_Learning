# Reinforcement Learning

強化学習（Reinforcement Learning）の理論について、
自分なりに理解した内容をまとめるリポジトリです。

## 📖 目的

- 強化学習の理論的な理解を深める
- 数式の意味や導出過程を整理する
- 各アルゴリズムの関係性を理解する
- 学習した内容を記録する

## 📚 学習内容

### 1. 強化学習の基礎
- Markov Decision Process (MDP)
- Value Function
- Bellman Equation

### 2. 動的計画法
- Policy Evaluation
- Policy Iteration
- Value Iteration

### 3. モデルフリー強化学習
- Monte Carlo Methods
- Temporal Difference Learning
- SARSA
- Q-learning

### 4. 深層強化学習
- Deep Q-Network (DQN)
- Policy Gradient
- REINFORCE
- Actor-Critic
- Proximal Policy Optimization (PPO)
- Soft Actor-Critic (SAC)

## 📝 ノートの構成

各アルゴリズムについて、以下の内容を整理します。

1. 概要
2. 背景・動機
3. 数学的な理論
4. 数式の導出
5. アルゴリズム
6. 考察
7. 参考文献
